# Societelos Kickoff Prompt for AI Assistant

**Context:** We are building a Jackbox-style local multiplayer game called "Societelos" for 5 high school students. It simulates a post-labor society where physical needs are met by an AI called "The Loom", and the players act as a hidden council managing the psychological well-being of the population.

**Tech Stack:**
- Backend: Node.js, Express, Socket.IO
- Frontend: Single-file vanilla HTML/JS/CSS (served from /public)
- CSS: Tailwind via CDN
- Visual Aesthetic: Matcha Latte (#f7f5f0 background, #1a2e22 text/accents). Minimalist, sleek administrative dashboard.

**Immediate Task:**
Generate `server/index.js` to initialize the Express/Socket.IO server on port 3000, and a basic `public/index.html` host screen that connects to the socket and displays a "Waiting for 5 nodes..." lobby screen using the specified color palette.
